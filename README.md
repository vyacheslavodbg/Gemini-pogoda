# AURA Geo Meteo & Alert System

Премиальное погодное и геоэкологическое приложение для **Варны** и **Одессы**.

## Состав системы:
1. `index.html` — Интерактивный веб-сайт и Telegram Mini App.
2. `bot.py` — Скрипт фонового мониторинга геомагнитных бурь и землетрясений.
3. `.github/workflows/alert_bot.yml` — Автозапуск бота 24/7 каждый час.
